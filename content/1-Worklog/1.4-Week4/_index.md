### Week 4 Objectives:

* Learn advanced security and system operations on AWS.
* Learn fine-grained access control with IAM Policies, Conditions and Permission Boundaries.
* Learn data encryption with AWS KMS and credential management with Secrets Manager.
* Learn threat detection (GuardDuty), security compliance (Security Hub), system operations and backup.

### Week 4 Achievements:

* Applied conditional IAM Policies and Permission Boundaries for fine-grained access control.
* Created and used KMS Keys to encrypt/decrypt data; used Secrets Manager to store credentials securely.
* Enabled and configured GuardDuty to detect abnormal activity; enabled Security Hub for centralized security alerts.
* Managed EC2 centrally and accessed it securely via Systems Manager; set up automatic backup with AWS Backup.
